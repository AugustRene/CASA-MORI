# CASA-MORI
Website 

## Project Description
A creative community dreamscape in which people can find inspiration and community though the arts and a common theme.
## Theme Interpretation
Casa Mori exists as a digital space meant for creative community. Dreamscape is used for inspiration when deciding the visual direction of the site. Community and digital space are embodied though call to community participation.



## Intended User or Player
Artists and people outside of the arts who may be into fashion and aesthetics. Age range: 18 - 30, gender: all inclusive.

## User or Player Goal
Find inspiration and information through theme and outside local events.



## Main Features
Theme Section:
This Section will host the most written content surrounding the current theme. It will also have accompanying visuals. 

Events:
A list of local events that surround the current theme.

Ispiration:
Visual inspiration.

Featured Artists:
This section is dedicated to artists featured on the site.




## JavaScript Features
The sidebar menu uses javascript to open and close.

## Responsive Design
Grid is used to prioritize responsive design without having to use media query. The only issue at the moment it overlap with the navigation bar.
